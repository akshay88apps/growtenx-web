# Provider SVG logos

Source: [Lobe Icons](https://github.com/lobehub/lobe-icons), `@lobehub/icons-static-svg` version **1.95.0**, MIT license (included).

Files use azure-color, aws-color, googlecloud-color, openai, langchain, and n8n-color from the pinned npm package. SVG geometry is unchanged. Intrinsic dimensions are set to 32 pixels and `currentColor` is resolved to `#e5edf7` for visibility as external images on the dark homepage. Brand colors are retained. Brand names and logos belong to their respective owners.

The adjacent visible names provide accessible labels; the images have empty alternative text to avoid repeating the names. No runtime icon dependency or third-party image request is needed.
